# Tripoli functionality inventory

Snapshot: **2026-11-25**, P8 first-increment status update **2026-11-26**. Goal from Yiming Zhang (they/them): “filament should inherit all functionalities of tripoli, and we add more.” This is a source inventory and implementation roadmap baseline, not a claim of numerical equivalence.

Sources are the supplied, read-only clones at **OGTripoli d906f70** (4.10.0.3 line) and **Tripoli 00dc941**. Every source cell below is relative to the containing Tripoli source directory and was checked by opening that file. An em dash means no counterpart established in the inspected snapshot; it does not prove permanent absence upstream. A reference to a parser, model or dormant menu is qualified in Notes and does not establish a working UI.

**Status:** done = the stated filament workflow exists for its supported inputs; partial = useful subset exists but the row's broader scope is incomplete; not done = absent in the reviewed implementation. Numerical parity is separately bounded by [the measured parity report](tripoli-parity.md), [oxide law comparison](oxide-correction.md) and [raw reduction limits](raw-reduction.md). For absence claims, the linked scope/implementation reference and the source-area audit below define the search boundary; no runtime test was used to infer absence.

**Work tags:** G = GUI/view only, including persisted presentation state; E = engine work in src/rawtims/; P = parser/interchange work; D = new or independently validated instrument/lab data required. G does not authorize numerical changes. Mixed tags intentionally identify cross-layer work. **EXCEEDS** identifies a verified scoped advantage over the counterpart, not a blanket ranking. Rows without EXCEEDS do not assert an advantage.

F1–F31 retain their identities. F32–F39 number the former unnumbered histogram, annotation, report, defaults, method, styling, help and resource rows. F40–F95 expose the remaining long tail. Umbrella rows (F18, F24–F31) overlap their detailed subfeatures; counts are planning rows, not a count of independent algorithms. F13 is a requested extension rather than a discovered dedicated Tripoli feature.

The original static inventory is supplemented by P1 implementation and source-oracle tests in [test_p1_window.py](../tests/test_p1_window.py). P2 exchange/report and inert-parser tests are in [test_p2_exchange.py](../tests/test_p2_exchange.py), [test_p2_legacy.py](../tests/test_p2_legacy.py) and [test_p2_reports_ui.py](../tests/test_p2_reports_ui.py). P3 composition/operator/covariance tests are in [test_p3_composition.py](../tests/test_p3_composition.py) and [test_p3_composition_ui.py](../tests/test_p3_composition_ui.py). P4 history/completed-folder tests are in [test_p4_history.py](../tests/test_p4_history.py) and [test_p4_history_ui.py](../tests/test_p4_history_ui.py); all seven P4 rows remain partial.
