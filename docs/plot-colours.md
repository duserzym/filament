## Symbols

Every cycle scatter (ratios, intensities and logarithmic/geometric views) uses 4.5 px squares in both Stacked and Auto-fit plot walls and the classic layout. Included cycles use `plot.included` with a 1 px `plot.pointHalo` edge matching the plot background. This halo is a Filament legibility deviation from Tripoli, which uses plain filled squares: it keeps overlapping cycles separable. Excluded cycles use a 1.2 px `plot.excluded` outline and an opaque plot-background centre so bands do not show through. The filled/hollow cue remains visible under colour-vision deficiency.

Off-scale excluded cycles retain hollow edge triangles, scaled from 10 to 7.5 px with a 1.2 px outline. Invalid crosses (7 px), selection rings (13 px), preview marks, hover behaviour and the 10 px pick radius retain their existing sizes or behaviour.

## Rendering and accessibility

Exact legacy light scientific RGBs and every baseline dark scientific token are retained. Excluded points remain hollow red squares, selected cycles square outlines, preview cycles hollow amber squares, invalid cycles crosses, and out-of-range rejected points hollow edge triangles. Block boundaries remain grey dash-dot lines. No changes to values, masks, plot ranges, band extents, legend wording, shortcuts or gestures.
